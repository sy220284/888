# ADR 0002：采用本地优先与本地世界状态

- 状态：已接受
- 日期：2026-10-05

## 背景

888 的输入与产物包含大量照片、视频、Mesh、Splat、深度图与世界状态，大体积数据不适合强依赖云端。

## 决策

项目工程、Canonical World State、SQLite、Artifact Store 默认保存在本地。

远程 Provider 只是某些能力的可选执行方，不成为项目数据真相源。

## 原因

- 大型 3D 资产本地读写更直接。
- 断网仍可打开项目。
- Provider 可替换。
- 避免云端状态与本地状态双重真相。
- 长期更适合桌面创作工具。

## 后果

需要解决本地磁盘占用、Artifact GC、数据迁移、Worker 与大文件管理、远程 Provider 结果同步。

## 约束

- Provider 返回 Candidate / Artifact。
- 正式世界状态由 Core 提交。
- 大文件不通过普通 IPC 传输。
