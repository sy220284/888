# ADR 0009：采用证据锚定的联想式世界推理

- 状态：已接受
- 日期：2026-10-05

## 背景

888 原有 Evidence + Hypothesis + Constraint Solver 能够保证世界状态可追溯，但在照片跳跃、室内外完全分离、零重叠观测等情况下，单纯依赖直接证据容易出现候选空间不足。

系统需要主动提出“可能是什么、可能怎么连接、下一步该验证什么”。

## 决策

采用：

> **Evidence-grounded Associative World Compiler**

新增 Associative Engine / Associative Prior Graph。

标准链路：

    Evidence
    ↓
    Associative Prior / Proposal
    ↓
    Hypothesis
    ↓
    Constraint / Verification
    ↓
    Canonical World State

## 核心原则

1. 联想负责扩大候选空间。
2. Evidence 与 Constraint 负责收敛。
3. Proposal 不直接成为 Verified。
4. Proposal 不直接创建 Observed。
5. 联想不能单独确定绝对尺度或精确 6DoF。
6. 新真实 Evidence 可以否决旧联想。
7. 联想来源、模型版本、支持与反对证据必须可追溯。

## 第一阶段范围

优先实现：

- Same Entity / Same Anchor 联想
- Zone / Portal 拓扑联想
- 联想驱动 Next Best View

大型知识图谱、长期跨项目联想记忆后置。

## 原因

这样可以提升：

- 跳跃照片关联能力
- 室内外世界连接能力
- 零重叠观测的候选发现
- 缺失区域补全质量
- 主动补拍效率

同时避免让生成式模型直接污染真实世界状态。

## 后果

需要新增：

- AssociativePrior / AssociativeProposal Schema
- Prior 生命周期
- Proposal Benchmark
- False High-confidence Association 指标
- 联想专项 Fixture
- Provider Capability
- UI 中的 Associative 状态表达
