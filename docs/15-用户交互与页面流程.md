# 15 用户交互与页面流程

## 1. 目标

888 内部技术复杂，但用户流程必须简单。

用户不需要理解 SfM、Factor Graph、Candidate、Splat 等术语才能完成主要操作。

## 2. 一级信息架构

```text
项目首页
├─ 素材
├─ 世界
├─ 问题与可信度
├─ 补拍建议
├─ 编辑
├─ 任务
└─ 导出
```

这些可以根据最终 UI 合并，但职责必须保持。

## 3. 项目首页

展示：

- 项目缩略图
- 最近打开
- 世界完成度
- 未完成任务
- 需要用户处理的问题
- 快速导入

主要动作：

- 新建项目
- 打开项目
- 导入照片 / 视频

## 4. 首次导入

用户拖入素材后：

```text
素材读取
↓
快速质量分析
↓
照片聚类
↓
初步空间关系
↓
开始重建
```

UI 显示真实工作内容，例如：

- 已读取 28 张照片
- 正在匹配可能属于同一房间的照片
- 已恢复 21 个相机位置
- 有 4 张照片暂时无法定位

禁止长期只显示“处理中”。

## 5. 素材页面

显示：

- 图片 / 视频
- 质量
- 时间
- 相机信息
- 所属 Zone
- 是否已定位
- 是否被世界使用

允许：

- 排除某素材
- 重新分析
- 查看 EXIF
- 查看与其他图片的匹配

## 6. 世界页面

默认进入 3D 世界。

支持：

- 自由查看
- 第一人称行走
- 原始相机视角
- Zone 切换
- Mesh / Splat 可视化
- Confidence Overlay
- Evidence Overlay

## 7. 可信度表达

用户可切换“世界可信度”。

至少区分：

- 已验证
- 真实观测
- 推断
- 假设
- AI 生成

点击区域可看到：

- 来源照片
- 当前判断
- 可信度
- 其他假设

## 8. 问题中心

集中显示真正需要处理的问题：

- 两个空间无法确定关系
- 相机位置冲突
- 两个对象疑似同一对象
- 某生成区域验证失败
- 某 Provider 任务失败

按影响排序。

## 9. 多假设交互

当系统无法确定：

```text
客厅可能位于：
A 一楼东侧
B 一楼西侧
C 二楼东侧
```

UI 可以：

- 预览每种假设
- 暂不决定
- 用户确认
- 查看需要什么新照片才能消歧

不强迫用户一定选择。

## 10. 补拍建议

展示：

- 建议站位
- 朝向
- 必须拍入的锚点
- 预计提升
- 解决哪些问题

例：

> 站在客厅门口向庭院拍摄，让门框与外墙同时入镜，可确定室内外相对位置。

后续可增加 AR 引导。

## 11. 编辑模式

用户选择对象后显示：

- 移动
- 旋转
- 缩放
- 替换
- 材质
- 删除
- 锁定

如果对象来自强真实证据，破坏约束的编辑要提示影响。

## 12. 证据检查

选中 Entity / Zone：

```text
当前对象
├─ 来源照片
├─ 重建算法
├─ Geometry 版本
├─ 验证结果
└─ 历史 Revision
```

高级信息默认折叠。

## 13. Candidate 比较

生成或重建多个候选时：

- 并排预览
- 原图视角对比
- 自动评分
- 用户选择

用户接受后才进入正式 Revision。

## 14. 任务页面

真实任务显示：

- 当前阶段
- 已完成工作
- 进度
- 预计资源占用
- Provider / 本地
- 可暂停 / 取消状态
- 失败原因

计划阶段也显示具体计划动作，禁止模板文案覆盖真实工作。

## 15. 失败体验

错误应回答：

- 哪一步失败
- 世界是否受影响
- 能否自动重试
- 用户是否需要操作
- 已完成结果是否保留

例：

> Gaussian Splat 训练因显存不足暂停。已保存相机与稀疏点云结果，可切换低显存模式继续。

## 16. 导出流程

```text
选择目标
↓
选择质量
↓
预检查
↓
显示需要转换的内容
↓
编译
↓
验证
↓
交付
```

目标：

- GLB
- Blender
- Unity
- Unreal
- Godot
- Web / XR

## 17. 状态恢复

用户重启应用后：

- 自动打开项目状态
- 显示哪些任务可恢复
- 不要求重新导入素材
- 不丢 Revision

## 18. 高级模式

默认 UI 隐藏算法细节。

高级模式可显示：

- Camera Frustum
- Point Cloud
- Anchor
- Portal
- Factor residual
- Worker
- Job
- Provider
- Benchmark

## 19. 用户决策原则

AI 可以自动做低风险决策。

以下情况建议请求用户：

- 两个高权重 Hypothesis 无法区分。
- 用户编辑与真实强约束冲突。
- 高成本 Provider 请求超预算。
- 操作会删除重要 Revision / Artifact。

## 20. 页面设计验收

核心任务应能用普通语言完成。

目标用户首次使用时，不需要阅读技术文档即可：

1. 导入照片。
2. 看见初始世界。
3. 理解哪些地方可信。
4. 根据建议补拍。
5. 编辑一个对象。
6. 导出。
